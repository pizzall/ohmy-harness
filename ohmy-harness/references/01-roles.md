# 01　角色与授权边界

## 主控

- 持有目标与授权，定首选方案、验收和任务单，选择负责人，记录任务及尝试，独立验收并向用户交付。
- 可直接做只读调查、复用已验收结果、运行确定性命令与验收、登记证据。对能整体交付和验收的生产工作，优先整单交给一个 Worker。
- 已授权的生产步骤需要宿主独占的工具或权限时，主控承担该步，登记独占原因、尝试、具体产物和验收。若图像工具只对宿主开放，主控出图并登记，页面 Worker 负责接入。无合适 Worker 时沿原方案查找等价入口或报告能力缺口。
- 主控写项目账本和本机调度记录。项目决定由主控核验证据后确认，涉及范围或权限变化时由用户先授权。

## Worker 与启动入口

- 每个任务只有一个当前负责人。Worker 在指定基线、工作区、读写范围和预算内生产，提交可定位候选版本、验证资料与阻塞原因。
- Worker 在分配的目录写工作产物，可提议项目决定。并发写使用隔离工作树或输出目录，任务账本由主控写入。
- 主控用当前宿主已授权的原生子 Agent、专用工具或非交互 CLI 启动。可获取原生会话 ID 时，在启动后补记到登记的尝试。返工优先续跑原负责人原会话。

## 验证方与用户

| 动作 | 负责人 |
|---|---|
| 复跑测试、解析文件、检查 schema | 主控或受委派的验证方，主控核对结果 |
| 按验收项复核语义与事实 | 主控或独立只读审阅者 |
| 采用已授权、满足同一标准的替代入口 | 主控，记明依据 |
| 批准新权限，或改变产品目标、可见行为、验收标准 | 用户 |
| 写入任务事实、结算样本、清退尝试临时文件 | 主控 |

用户裁决只阻塞真正依赖该决定的分支。其余分支照常验收和登记。
